# Database Fundamentals

## 1. What is Data?

Data is a collection of facts or information that can be stored and processed.

## 2. What is a Database?

A database is an organized collection of data that can be stored, accessed, managed, and updated efficiently.

## 3. What is DBMS?

DBMS stands for Database Management System.

It is software used to create, manage, and interact with databases.

Examples:
- PostgreSQL
- MySQL
- Oracle Database

## 4. What is RDBMS?

RDBMS stands for Relational Database Management System.

It organizes data into tables consisting of rows and columns. Tables can be connected through relationships.

## 5. What is PostgreSQL?

PostgreSQL is an open-source relational database management system used to store, manage, and retrieve application data.

## 6. What is SQL?

SQL stands for Structured Query Language.

It is used to communicate with relational databases.

## 7. Database Terminology

- Database: Organized collection of data
- Table: Data organized into rows and columns
- Row: A single record
- Column: An attribute of a record
- Query: A command sent to the database
- Primary Key: Uniquely identifies a row
- Foreign Key: Connects related tables

## 8. DBMS vs RDBMS

A DBMS is a general database management system.

An RDBMS is a type of DBMS that organizes data relationally using tables and relationships.
